# OpenShelf

OpenShelf is a community-driven platform that enables users to lend, borrow, and eventually trade physical books with people nearby.

## Features

- User Authentication
- Book Listings
- Book Lending Requests
- Wishlist
- Ratings & Reviews
- Local Discovery

## Tech Stack

### Backend

- NestJS
- PostgreSQL
- Prisma
- JWT Authentication
- Cloudinary

### Frontend (Planned)

- React
- TypeScript
- Tailwind CSS
